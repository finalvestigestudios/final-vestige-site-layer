## New actionable quality gate: 960px and actual DPR

A 960px wide staging derivative yields 1 image pixel per CSS pixel only up to **960 CSS px at DPR 1**, **480 CSS px at DPR 2**, or **320 CSS px at DPR 3**. These are mathematical limits, *not observed render widths*. The five published PNG `<img width=1024>` attributes do not prove rendered CSS width is 1024px. Thus a blanket 960px replacement can visibly soften desktop or retina layouts even while stored bytes shrink. In particular, do not force the 960×960 Halifax historical map without independently testing legible labels and keeping full-size zoom access. A CDN-optimized `currentSrc` can make a large WordPress original irrelevant to visitor transfer.
