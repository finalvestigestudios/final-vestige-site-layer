4. **P1 — only after rights clearance:** For each authorized exact asset: record original URL, catalog identifier, reuse rationale/license, credit, master SHA-256, target max **960px width** preserving aspect ratio/no upscaling, image-format visual QA, WordPress media item, responsive output and unchanged permalink/caption. No bulk scraping, no hotlink circumvention, no raw Gutenberg replacements.
5. **P2 — release evidence:** Compare the same-page mobile waterfall, image transfer bytes and LCP/CLS against an unchanged baseline. A “76% reduction” requires independently reproducible before/after measurements; otherwise leave it unclaimed.
