**Verified audit date:** 2026-10-30. **Scope:** 61 published WordPress posts, 355 source `<img src>` references, 288 offsite stored sources (81.13%; 170 external + 118 Commons redirects); 60 first-party and 7 first-party Jetpack proxies. Site QA PR [#154](https://github.com/finalvestigestudios/final-vestige-site-layer/pull/154) earlier measured 286 offsite sources. The two-reference delta is localized to posts **291 (Teton Dam)** and **285 (Three Mile Island)**: older QA CSV counted five offsite references each, while the newer current-CMS snapshot counts six each. Both have an \`i0.wp.com\` image whose path points at a **different origin** (National Archives blog and Squawkpoint, respectively), not \`/finalvestige.com/\`. This is a classification/input discrepancy, not a proven source failure; re-run Site QA's classifier on the same fixed snapshot to distinguish its input from output. This worklist complements PR #154, not a rewrite of that team's code.

**Do not misreport:** The founder's “42 broken images” has **not** been established in a real browser, and the claimed 76% image-weight reduction is **unmeasured**. Source-only audit cannot prove either. Media Library contains 110 image records, totaling 64,900,772 **original** file bytes; 13 originals exceed **1.5 MiB**. These are not page-transfer bytes. Existing responsive WordPress/Jetpack variants may already serve smaller files. 305 stored image tags omit explicit dimensions; dynamic image sizes may still be supplied in rendered HTML.

**Machine-readable evidence:** `qa/media-recovery/parts/01.json`–`08.json` capture every source URL, owning post/slot, stored alt, known dimensions and explicitly unknown browser HTTP status. `source_record_candidates_20261030.json` maps 18 specific images to archival record reviews (Florida Memory, USCG, USGS, NASA), with rights and ≤960px constraints. `viewer_spotchecks_20261030.json` records 20 web-viewer attempts, **not browser failures**. `oversize_originals_20261030.json` names 13 large source files. `validate_inventory.cjs` validates counts, URLs and safety gates, while `test_validate_inventory.cjs` contains nine fail-closed Node tests.

The State Archives catalog [N031889](https://floridamemory.com/items/show/141398) identifies **State Board of Health headquarters, Pahokee, 1928** and names personnel; it **does not** establish the FV alt's “disaster-response headquarters after the 1928 hurricane.” Suggest fact-based alt **“State Board of Health staff at the Pahokee headquarters in 1928.”** This is a source-backed editorial correction recommendation, **not a live WordPress edit**. The archive's [MSF-PB11548-001](https://floridamemory.com/items/show/340182) is a **2001 color slide** of the historical African American mass burial site, not a 1928 contemporary photograph. Preserve the 2001 date in attribution and captions. Both catalog identifiers and exact `/fpc/` image paths are independently matched. Rights and credit remain individual-item review gates.

## Work queue, sorted by verifiable value

1. **P0 — broken-image proof, not guesswork:** Logged-out Chrome on desktop and mobile for high-risk source-dependent posts **268 (Archimedes; 10 offsite/10), 432 (Okeechobee; 7/7), 418 (1946 tsunami; 6/6), 407 (Hebgen; 8/8), 434 (Apollo 1; 5/6), 621 (Malbone; first-party comparison)**. Collect rendered `currentSrc`, `naturalWidth`, network status/redirect/content-type and screenshots for each failed image, plus LCP/CLS and bytes. Viewer 403/unsupported observations for media.defense.gov and USGS S3 are **not browser HTTP status evidence**.
2. **P0 — precise source-to-image match:** Follow authoritative linked records and actual reproduction restrictions. Do not replace a historical photograph with a merely similar image. Preserve source credits and chronology.
3. **P1 — oversized original examples:** Malbone post 621 references original photos of **5,553,669 bytes** (`edit-017-v02-nypl-5003296-original.jpg`) and **4,798,395 bytes** (`edit-017-v01-malbone-tunnel-generalpunger-original.jpg`); smaller 1024px Jetpack variants exist. Verify browser transfer **before** rewriting or recompressing. 13 large library originals may not even be used inline. Prevent conflating summed library originals with page weight.
4. **P1 — only after rights clearance:** For each authorized exact asset: record original URL, catalog identifier, reuse rationale/license, credit, master SHA-256, target max **960px width** preserving aspect ratio/no upscaling, image-format visual QA, WordPress media item, responsive output and unchanged permalink/caption. No bulk scraping, no hotlink circumvention, no raw Gutenberg replacements.
5. **P2 — release evidence:** Compare the same-page mobile waterfall, image transfer bytes and LCP/CLS against an unchanged baseline. A “76% reduction” requires independently reproducible before/after measurements; otherwise leave it unclaimed.

**Reuse constraints:** [NASA Brand Center](https://www.nasa.gov/nasa-brand-center/) describes source-credit, third-party-rights, recognizable-person and nonendorsement caveats; [USCG photo archival page](https://www.history.uscg.mil/Our-Collections/Photos/igphoto/2002268810/) says generally public domain unless otherwise noted and requires appropriate credit. Florida Memory's public archive record and Rights indicator do **not** authorize blanket mirror/republication without item-level review.

**Safety:** No production WordPress writes, licensing assumptions, asset downloads, speculative 42-image “fixes,” homepage design edits or expenses. PR is a source-only draft.
