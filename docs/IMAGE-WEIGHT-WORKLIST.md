## Browser identity and wire-evidence hardening — October 30, 2026 (late sprint)

**Verified failure mode in the previous audit code:** An HTML `src` or lazy `data-src` could equal the stored historical photograph while the browser actually decoded an **unrelated `currentSrc` selected by `srcset` or a fallback**. Previously the stored image could be called `loaded_in_probe_browser` based on the unrelated pixels. The source-only inventory and earlier archival matches were NOT evidence that this happened in production, but the test fixture demonstrated a real false-positive path.

**Fixed on PR #183:** `browser_probe_core.cjs` now demands that the decoded `currentSrc` have the same conservative identity as the stored source before asserting a loaded or broken stored image. It records `current_src_identity_verified` and returns `current_src_identity_unverified` when only the HTML source/lazy placeholder matches. Request status and bytes are tied to the decoded `currentSrc`, not a stale `src`. Existing Wikimedia Commons redirect and WordPress Jetpack identity cases remain supported. This errs on the side of additional review when responsive derivatives change filenames without a provable identity link.

**Independent 76%-measurement protection:** Comparator `compare_wire_core.cjs` now requires probe schema **v3**, successful decoded-source identity, and a matching real image network row (source URL/redirect alias, status and encoded byte count) for every supposedly measured stored-image slot. It rejects fake per-slot response sizes even when the aggregate network total is unchanged. Shared requests serving multiple DOM image elements remain valid and count only once in the page total. Old v2 runs are NOT eligible as proof of weight reduction. This is an integrity guard, not proof that any live asset was fixed or that the claimed 76% saving occurred.

**Test evidence:** 61/61 exact GitHub committed-source cases passed in an isolated V8 replay with a minimal URL shim: 12 existing browser core, 15 Commons, 9 new decoded-source adversarial tests, 25 comparator tests. **Not native Node CI or live Chrome.** Browser runtime now emits `probe_version:3`.
