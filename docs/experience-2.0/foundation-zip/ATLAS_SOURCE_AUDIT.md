# Evidence Atlas — truthful first dataset

Confirmed through the connected Final Vestige WordPress site: six *published* investigation posts and their URLs, IDs and themes. The file `atlas_seed_catalog.json` is a **review queue**, not a geographically verified map.

**No coordinates have been assigned.** A map marker requires authoritative place confirmation, a defined uncertainty radius or administrative region, a source and an editorial review. A story mentioning a place does not prove its event and its artifact have the same location. The Franklin expedition is a useful example of why one pin may be misleading: the Victory Point Note, the ships and the expedition route are distinct kinds of geography.

## Before interactive mapping

1. Read each published story and its original linked primary sources.
2. Choose one of: *event point*, *artifact discovery point*, *geographic region*, *route*, *unknown*; store separate geometry per distinct fact.
3. Record coordinate source link, precision, approximate date, edition/version and approval. Do not mix event date with date of later museum display or photograph.
4. Only then enable pins; map layers and routes require explicit supporting sources, not inferred connections.
5. Preserve a navigable HTML list with the same real investigations, even if JavaScript or a map engine fails.

## Publication gate

The six linked posts are suitable for a **text/list preview** now. They are *not* suitable for a literal world-map plot yet. This prevents a polished but fictitious visualization.
