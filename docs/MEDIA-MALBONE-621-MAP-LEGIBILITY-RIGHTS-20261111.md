# Malbone — rights-aware image performance, no map-detail loss (November 11, 2026)
**Scope: two oversized first-party originals in published post 621. This is an offline-only, isolated PR #1703 media-recovery change; Site QA #154 owns browser evidence, PR #183 owns the 66-post worklist.**

Read-only [published article](https://finalvestige.com/2026/08/23/six-miles-an-hour-malbone-street-wreck/) and frozen WordPress media metadata establish two photos/images: **621:0** is the 2021 surviving-tunnel photograph credited to *GeneralPunger / Wikimedia Commons CC BY-SA 4.0* (4,000×3,000 px, 4,798,395 stored bytes); **621:1** is NYPL image **5003296**, the **1903 Brooklyn Rapid Transit system map** (5,667×3,831 px, 5,553,669 stored bytes). The latter is a contextual 1903 system map, **not a surveyed diagram of the 1918 wreck curve**. Combined stored originals: **10,352,064 bytes**, *not measured visitor wire bytes*.

**New editorial risk:** Blindly replacing the detailed 1903 rail map with only a 960×649 JPEG loses fine station/route-label legibility. A 960px inline preview is conditional on retaining an accessible full-detail same-map zoom/source experience and an explicit *1903 predates 1918* caveat. The surviving-tunnel photograph may be conditionally 960×720, provided exact-source verification, credits, link to [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) and any appropriate edit notices are respected. Substantive creative adaptations must comply with applicable ShareAlike terms; ordinary technical resizing alone should not automatically be labeled creative adaptation.

**Archival provenance:** [NYPL rail company research guide](https://libguides.nypl.org/nyc-rail-transit/companies) specifically identifies digital image **5003296** and the 1903 BRT subject; direct catalog [item](https://digitalcollections.nypl.org/items/c745e730-d2a9-012f-5ecc-58d385a7bbd0) returned a *web-retriever 403*, so per-item metadata and image-level rights remain for human review. NYPL's [rights guidance](https://qa-digitalcollections.nypl.org/about) supports reuse of materials labeled public domain and requests 'From The New York Public Library' plus source link, but **does not clear this exact item automatically**. The site itself asserts public-domain belief for this map. GeneralPunger's exact Commons item has not been independently identified, even though the article credits CC BY-SA, so both are on rights HOLD before derivative preparation.

**Read-only web retrieval observations:** The article's Jetpack image endpoint for 621:0 carried `?resize=4000%2C3000&ssl=1` and timed out in the retriever; 621:1 carried `?resize=5667%2C3831&ssl=1` and was rendered by the retriever. These are neither origin HTTP codes nor real logged-out browser downloads; no bytes, natural dimensions or site-wide 76% reduction were measured. Large URL query dimensions only flag a *potential* optimization opportunity.
