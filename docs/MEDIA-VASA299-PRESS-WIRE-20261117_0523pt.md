## New executable offline acceptance gate

[Validator](../qa/media-recovery/validate_vasa299_press_wire_20261117_0523pt.cjs) rejects false browser statuses, inflated reuse rights, claimed exact candidate 389, unverified master hashes or crop identity, altered dimensions, and any production-authorized fields. It also exports `assessWirePair`, a **data consumer, not another collector**. Input: the same published URL/revision, logged-out cold CDP traces before and after, full image-request inventory, request ID, final currentSrc, HTTP/MIME, decode and natural pixels, CDP Network.loadingFinished encoded-transfer bytes, screenshot SHA-256, independent visual review, same viewport/DPR/UA, no disk or service-worker cache. Dropped image slots HOLD; invalid or missing evidence HOLD. A valid pair reports **page-only** percent reduction from summed transferred bytes, not a sitewide 76% claim. CDP encodedDataLength is network bytes and may include response overhead, not raw file content bytes.
