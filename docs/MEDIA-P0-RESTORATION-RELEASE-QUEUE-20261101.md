The published source census still has **61 posts, 355 image references, 288 external stored references, 13 WordPress original files >1.5 MiB**. Those 13 media originals occupy **43,522,829 bytes** of storage; this is not what readers download. Do not confuse the `42` *reported* broken source images with the source-only **10** selected priorities here.

Use the already committed strict `qa/media-recovery/browser_probe_chrome.cjs` v3 and `compare_wire_runs.cjs` in a network-enabled logged-out QA browser, with identical scope, viewport, browser build and cache-disabled scroll protocol; separately measure weight on baseline and after any approved change. Zero-byte unknowns, broken baselines, substituted artwork or different ALTs cannot be included in a compression success numerator.
