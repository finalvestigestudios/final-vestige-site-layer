# Image-transfer source attribution hardening — 2026-11-04 Pacific / 2026-11-05 UTC

**Scope:** independent Media Recovery draft PR #183, offline image-transfer comparison only. This change does **not** modify WordPress, existing Site QA #154's browser probe, homepage visuals, image binaries, hosting or licensing.

## Concrete defect and remediation

The existing `compare_cold_image_wire_v1.cjs` reconciled a CDP request ID and bytes but *did not independently require the stored article image, the browser-decoded `currentSrc`, the linked request URL, and the final response URL to refer to the same archival image*. A stale or deliberately mismatched request could therefore be counted as genuine historical-image savings, subject to other synthetic fields being marked true. It also allowed mismatched DOM/CDP MIME declarations and a missing per-page wire error ledger.

**Patched:** reuse `browser_probe_core.cjs::sameSource()`, the previously reviewed conservative provenance equivalence function. Require stored `src` ↔ `currentSrc` ↔ CDP `request_url` ↔ CDP final response URL continuity; compare normalized response MIME on both records; require an explicitly present empty `article_wire_evidence_errors` array. This accepts legitimate first-party Jetpack `?fit=960,720` numeric resizing but rejects an unrelated historical photo and PNG-to-WebP `?format=webp` as silently equivalent. Fail-closed HOLD is preferable to a false measured reduction. This is **not** pixel-hash equivalence, proof of rights, or visual/scene parity.

**Evidence:** [committed source](../qa/media-recovery/compare_cold_image_wire_v1.cjs) blob `0192362c978a6bca30e83f9ae78ab22015b49a1f`, commit `484e45c7e5b979f6043828a3431cf60c8f977f7d`; [committed tests](../qa/media-recovery/test_compare_cold_image_wire_v1.cjs) blob `8774145823f6dbaed580a267cbea43d540d0e674`, commit `4a61fc9d03337c41eeecc87ce304a46c7e2d8371`. An independent replay against **prior blob** `1e826ae202410bd317972aec7b859ff6d38414df` passed 31/36 tests and failed *exactly the five newly added negative controls*; against patched blob, **36/36 passed** using a V8-compatible URL shim with the exact existing GitHub-fetched identity helpers. This is source-level testing; native Node CI and real browser remain **not executed**. Do not claim real 76% savings from synthetic fixtures.
