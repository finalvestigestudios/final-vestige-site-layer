# Source-image query-token fidelity: 68 WordPress edit/view slots (2026-11-15)

**Finding:** 2 of 24 originally query-bearing image URLs lose the source `itok` parameter in WordPress's rendered Jetpack proxy URL, while 22 retain all upstream parameters. The sample comprises **68 distinct image slots across ten posts** (frozen 26+42 authenticated edit/view audits; source blob SHA checks in code). Of 68, 44 had no source query string. The two live posts were independently re-read in WordPress edit and view contexts this afternoon and remained published with unchanged source/view URLs.

* **288:5, Honda Point:** authored `https://www.usni.org/sites/default/files/styles/hero_image/public/LWF-PRO-3-20%201_0.jpg?itok=ex2XHVlK` → rendered `https://i0.wp.com/www.usni.org/sites/default/files/styles/hero_image/public/LWF-PRO-3-20%201_0.jpg?ssl=1`. No download, derivative or upload.
* **418:5, 1946 Hilo tsunami:** authored `https://d9-wret.s3.us-west-2.amazonaws.com/assets/palladium/production/s3fs-public/styles/full_width/public/media/images/19460401_UNKNOWN_37-012_copy.jpg?itok=ASMRCahz` → rendered `https://i0.wp.com/d9-wret.s3.us-west-2.amazonaws.com/assets/palladium/production/s3fs-public/styles/full_width/public/media/images/19460401_UNKNOWN_37-012_copy.jpg?ssl=1`. [USGS exact-scene media catalog](https://www.usgs.gov/media/images/damage-hilo-tsunami-struck-april-fools-day-1946) describes a debris-covered vehicle, labels the image public domain **but attributes the original source as unknown**. Verify pixel identity, current rights statement and dimensions before any copy or caching.

**Why it matters:** Drupal [ImageStyleInterface](https://api.drupal.org/api/drupal/core%21modules%21image%21src%21ImageStyleInterface.php/interface/ImageStyleInterface/main) defines `itok` as a derivative token for preventing unauthorized image-style generation. Some upstream styles require it; however, Jetpack may already hold a usable CDN copy. Therefore this is a **real WordPress URL-identity loss**, **not proof of failed visitor images**. [Jetpack Site Accelerator](https://jetpack.com/support/site-accelerator/) documents `i0.wp.com` routing and separate CDN behavior. HTML entity `&#038;` and added Jetpack `ssl=1` are not inherently failures.
