# The Link Is Not the Record — Source Reliability Desk

*Free practical reference · Final Vestige Studios · November 16, 2026 · original writing and framework. This worksheet may be reproduced with attribution.*

## Before citing the source

A link can work and still lead to an incomplete archive. A document can exist but be inaccessible in the browser. An open-access portal may contain both reusable and restricted media. Treat these as separate checks, not one green tick.

### 1. Write down the identity of the thing you actually found

- Institution and custodian: ______________________________
- Exact collection / record title: ______________________________
- Identifier (NAID, report number, DOI, case ID): ______________________________
- Original institutional URL: ______________________________
- Item or version date: ______________________________
- Access check date (include timezone): ______________________________
- Was the **underlying item** opened? [ ] Yes [ ] No [ ] Partial

### 2. Assign a retrieval state — not a verdict

| What happened | What you may say | What you must not say |
|---|---|---|
| Institutional page opened | Its landing record responded | All files are available or correct |
| App shell loaded | An interface loaded | Search or download was tested |
| 403, 405, 406 or similar | This request was restricted/rejected | Everyone sees a broken link |
| Timeout | This request did not finish | The source no longer exists |
| Document oversized | This reader could not process it | The document is invalid |
| Index record, no digital file | A description is discoverable | The file is online or absent |
| Item opened | An actual item was inspected | It is necessarily authentic, complete or reusable |

### 3. Check the rights at the same granularity as the evidence

- Asset creator or photographer: ______________________________
- Holding institution and accession/item ID: ______________________________
- Original item URL and date: ______________________________
- Exact item license / usage statement / source: ______________________________
- Copyright, trademark, privacy, donor, cultural or publicity issues remaining: ______________________________
- If reproducing: credit line, caption, factual alt text, and permission record: ______________________________

**Rights are not inherited from the homepage.** The Smithsonian's [CC0 FAQ](https://www.si.edu/openaccess/faq) limits its unrestricted rights statement to designated assets; the [Rumsey map permissions](https://www.davidrumsey.com/about/copyright-and-permissions) identify later works and non-downloadable exceptions; [Veterans History Project use guidance](https://www.loc.gov/collections/veterans-history-project-collection/about-this-collection/using-the-collection/) distinguishes descriptive discovery from viewing or copying. These sources were last checked November 16, 2026.

### 4. The citation you can defend

**I inspected:** [institution], [specific item], [identifier], [dated edition], [item URL] on [date/time zone]. **It shows:** [one directly observed fact]. **It does not establish:** [missing file, coverage gap, unverified quotation, rights limitation]. **Next verification:** [precise action].

Do not write *records did not exist* because one search was empty. Do not write *the link is dead* because a bot was denied. Let the evidence say what it actually knows.
