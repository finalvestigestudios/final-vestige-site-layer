## Verified observation and its limitation

Seven exact `https://www.floridamemory.com/fpc/...jpg` image URLs in post **432** from the immutable October 30 source snapshot were opened using an independent public-web retriever on November 18. **All seven returned a wrapper message**: `500 Redirected to https://floridamemory.com/fpc/...jpg which is not accessible via this tool`. Each redirects from `www.floridamemory.com` to the apex hostname while retaining the image path. **This is a tool-side redirect-following/access failure.** It does **not** establish that the final publisher served HTTP 500, the published Jetpack image failed, or any user saw a broken image. Do not include these seven in a tally of 42 verified broken visitor images.
