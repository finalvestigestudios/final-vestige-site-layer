## Capture adapter contract — for the existing Site QA collector
`capture.schema=fv-guest-cdp-image-capture-v1`, `capture_method=chromium-cdp`, `real_capture=true`; each `runs[]` has a unique ID, phase before/after, exact page URL, browser_version, user_agent, network_profile, viewport width/height/dpr, cold-cache + full-scroll + lazy-image-settled + request-complete flags, all `dom_images` with count/current_src/natural_width/height/visible/complete/request_id/screenshot_ref, and all CDP `image_requests` with unique id, URL/final URL, resource_type=image, actual HTTP status (zero only with recorded network_error), MIME, encoded_bytes, and from_cache=false. Rendered `currentSrc` is intentionally NOT presumed equal to stored original `src`: Jetpack or publisher redirects may rewrite it. The request identity join is mandatory. A screenshot path is only a *reference*, not proof the file was checked.

- **Candidate failure:** visible + complete image with natural size 0×0 and failed HTTP/transport/non-image response AND a screenshot reference. Output always says **BROWSER_FAILURE_CANDIDATE_REVIEW_SCREENSHOT**, never a verified customer failure without visual review.
- **Evidence of healthy decode:** natural pixels positive, completed, successful image-type network response.
- **Weight comparator:** same article, browser version, UA, viewport/DPR, network profile, cache-disabled complete full-scroll before/after page request set. Sum **CDP image request encoded bytes**, not CMS original storage. Distinct requests count by ID; aliased URL references aren't independently downloaded per tag. Check render parity (not fewer images), screenshot/visual integrity, attribution and CLS/LCP separately. Reduced bytes on a single page do **not** imply a 76% site-wide reduction.
- **Site-wide claim** remains explicitly null until a complete, documented common cohort and matched per-page pairs are verified and reviewed. Legacy **61 posts/355 img**, current **66/361** are *different frozen populations*, not interchangeable denominators. **42 broken is an allegation**, not 42 browser-verified HTTP errors. **13 WP media originals = 43,522,829 bytes stored** and not proven wire transfers.
