# Nov 12 P0 canonical-source and rights path handoff (read-only)

This is a **source/copyright/identity research packet**, not a production fix, logged-out visitor diagnosis, downloader, browser collector or approval to mirror. Historical scope is **61 posts / 355 images, 288 offsite**, with **42 reported failures not confirmed by authentic guest browser evidence**. The newer 66-post cohort is separate. The 76% claim is unmeasured. Fifteen originals >1.5 decimal MB total **47,096,779 stored bytes**, not actual network transfer.

## High-value source observations
1. **Sunshine Skyway 287:5:** archived inline `https://stpetecatalyst.com/wp-content/uploads/2020/04/Skyway-Bridge-documentary.jpg` produced a 404 in an independent *web retriever*. The same publisher's `https://media.stpetecatalyst.com/uploads/2020/04/Skyway-Bridge-documentary.jpg` displays the disaster photograph. The publisher's photo credit/University Press of Florida means **do not rehost** without permission. Florida Memory [RC09236](https://www.floridamemory.com/items/show/32082) depicts the disaster but is **a different photograph** and cannot be silently substituted.
2. **USGS Hebgen 407:1:** official [USGS item](https://www.usgs.gov/media/images/hebgen-lake-fault-scarp-1959) calls the photograph **public domain**, photographer **J. R. Stacy**, and its `Original` link points to `/thumbnails/image/img7535.jpg`, while the published post still uses `/img7535.jpg`. The canonical image **displays** in the independent retriever (1000×1000 displayed), but the old link was classified as unsupported octet-stream by that retriever. Neither is guest HTTP/decode proof nor binary equality. A 960px *conditional* derivative must retain full detail and original attribution.
3. **Coast Guard 418:1:** [USCG official photo catalog](https://www.history.uscg.mil/Our-Collections/Photos/igphoto/2002905913/) lists **VIRIN 210330-G-DE713-0002.JPG**, same filename as the published media.defense.gov source. The agency explicitly calls it **public domain and cleared for release**, subject to photo credit and DoD use limitations. The catalog spells the keeper's name **Anthony Pettit** (not Petit). Source filename/catalog match is not cryptographic proof of exact scene, rendition or pixels.
4. **UCS TMI 285:2:** the old `blog.ucsusa.org` image URL points toward `blog.ucs.org` in the retriever but the new location was not fetchable there. Licensing for the publisher's illustration remains unknown.
5. **USCG Scotch Cap 418:2:** the history.uscg.mil original returned a 403 **retriever wrapper observation**, while a secondary Lighthousefriends URL displays an apparently related image. Same pixels and rehosting rights unknown.
6. **TMI 285:5:** original SayMedia source returned a retriever 404. Wikimedia scene is not the same photo; no quiet substitution.

**Florida reuse distinction:** Florida's [official photo-selection policy](https://www.floridamemory.com/learn/about/selections.php) indicates digitized items must be rights-unrestricted; its [2017 state press release](https://dos.fl.gov/communications/press-releases/2017/florida-memory-achieves-major-milestone-with-the-200-000th-historical-photograph-added-online/) describes the online photos as free of copyright restrictions with State Archives credit. These general policies do not prove a *different-scene* image is a drop-in repair. Check the item, donor provenance and credit.

## Site QA handoff
