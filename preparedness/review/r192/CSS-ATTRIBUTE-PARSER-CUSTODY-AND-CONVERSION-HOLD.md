- **Found reproducible parser discrepancy:** HTML `HTMLParser` provides duplicated attributes as a list, but R191's `dict(attrs)` keeps the **last** value. Browsers generally honor the **first** attribute. `<div style="background:url(https://evil.test/a)" style="">` could be admitted by the old CSS gate while a browser may load the first style's remote resource. Duplicate `fill`, `stroke`, `mask`, `href`, `type`, etc. likewise create parser ambiguity. R192 rejects all duplicate attributes before value normalization, avoiding browser-versus-Python disagreement.
- **Found CSS tokenization gap:** CSS comments can split token spellings such as `@im/**/port` or `u/**/rl(https://...)`. Old regex checked raw escaped CSS but not comment-normalized CSS. R192 normalizes comments outside CSS quoted strings, rejects unmatched markers, then uses existing import/URL/resource allowlist. Preserves legitimate local `url(#fw-pat)` SVG references.
- Both guards apply automatically to six authored companion-tool HTML files and six disposable generated WordPress draft exports because they extend the existing R191 scanner. The R191 native preflight's source-pin is updated to the exact revised Git blob; an independently altered scanner remains blocked.
