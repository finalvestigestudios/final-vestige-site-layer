## What R44 establishes

`preparedness/tools/reviewer_private_zip_gate.py` wraps the
R43 **entire offline, escaped source-reading HTML desk** inside a deterministic
in-memory ZIP, with one canonical private manifest. For the original corpus,
there are 38 HTML pages (35 articles + water-planner + index + shared sources)
and one manifest, for 39 members. R43's 1,959 individual citations,
367 original article-specific reading relationships, 43 cross-cluster fallbacks,
30 global repeated-URL groups (including uncited source variants), exact
source URLs and contributor notes remain **distinct**.

- The ZIP carries HTML as data, without scripts, source-link activation,
  tracking, network dependencies, or upload/automatic publication behavior.
- Member order, permissions, timestamps and compression are fixed. Verification
  re-encodes the complete archive and rejects byte-noncanonical ZIPs, trailing
  polyglots, duplicate/extra/path-traversing members, bad metadata, oversized
  expansion and changed or non-UTF8 pages.
- A strict JSON manifest binds every exact R43 source page and its byte length
  and SHA-256. The verifier requires two caller-supplied, independently pinned
  trust anchors: **R42 original dossier fingerprint** and **R43 rendered-desk
  manifest fingerprint**.
- The baseline mandatory 13th private preflight now performs an in-memory
  build/readback/compare for the full 35+1 corpus. It does **not** save or
  distribute the actual ZIP; optional legitimate external custody workflows
  must be approved independently. This gate checks consistency, not the
  human source verification that remains unfinished.
- The complete R44 test suite is synthetic and exercises altered bundles,

  mutations. No reviewer responses, credentials or production exports are used.

## Trust boundaries

A self-calculated SHA-256 fingerprint is NOT a signature or identity proof.
To detect an attacker who can edit the package and its manifest, the R42 and
R43 fingerprints must come from separately controlled trusted custody records.
The mandatory machine preflight derives these from the frozen upstream machine
chain and **cannot** claim an externally authenticated human trust anchor.
There is no private archive delivery, signature key provisioner, operational
reviewer roster, permanent receipt ledger or atomic checkpoint service.

**Important privacy:** The HTML views contain original contributor reading
notes and potentially review-specific material. Treat any package produced by
an authorized offline caller as sensitive private material. Encrypt in transit
and at rest; do not put it in repository commits, GitHub issues/PRs, WordPress,
email attachments or a publicly reachable storage bucket. The committed
implementation contains only generic source code, tests and this document.
