These parameters are labels, **not proof of human traffic**. Neither invent nor publicly activate placeholder asset_id.

**Minimal event contract, consent-gated where applicable:**
- qualified_human_session: unique privacy-safe session after bot/internal filtering, source tagged where permitted; no raw IP, emails, fingerprints or cross-site identifiers stored.
- article_view: topic page actually rendered; not a sale.
- article_to_focus_click: user action from source article to the one existing Focus route; not a signup.
- confirmed_lead: only native Jetpack/provider confirmed opt-in evidence + deduplicated eligible record; not merely a button click.
- offer_guide_view: high-intent buyer-guide render; not checkout.
- affiliate_outbound_click: permitted user click to a **verified approved** merchant URL, recorded only after approval and consent QA; **currently impossible** because purchase control disabled.
- verified_checkout_start: only if merchant actually supplies this event; otherwise UNKNOWN.
- merchant_confirmed_order: authoritative paid order from merchant/Payhip, not UTM/click/session.
- paid_affiliate_commission: partner-reported approved commission, distinct from order count, may be provisional until settled.
- refund / chargeback / fees / settled_net: reconcile actual settled values in reporting periods.

**KPI:** realized net revenue per 1,000 qualified human sessions = 1000 × (settled receipts + settled commissions − refunds − chargebacks − platform/payment fees directly attributable) / deduplicated qualified human sessions **only for the same attributable cohort**. **Hold constant:** audience and topic intent, positioning, merchant offer, disclosure, CTA text, viewport, referral routing, published URL if randomized, loading budget, measurement/consent rules. Randomize only after authorization and independent QA, using existing first-party experiment capability. Do not run an unconsented identifier or create an analytics vendor.

**Risk and protection:** video could distract, slow mobile load, lower accessibility, or overstate the psychology. Reuse an optimized, self-hosted or already approved file only after rights/caption/performance checks; default preload=none, controls visible, poster dimensions stable, text remains complete with JS off, reduced-motion respected, no external player by default. No autoplay. If the cost threshold is not met, remove the video arm and retain the complete text alternative.

**Primary endpoint after partner approval:** settled attributable net revenue per 1,000 qualified human sessions, not video plays, CTA clicks or email captures. **Secondary:** consenting confirmed leads, landing-to-guide view, qualified offer intent. Require approved power/minimum decision threshold and seven-/thirty-day windows **before** analyzing; for low sample, report descriptive results and credible uncertainty, no winner declaration.
