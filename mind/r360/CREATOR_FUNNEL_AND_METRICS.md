## Measurement contract, absolutely no new production script in this sprint
Unique actual `utm_content=asset_id`, `utm_source=tiktok|youtube|instagram...` as verified, `utm_medium=organic_social`, `utm_campaign=mind_pilot_2026_11`. Record source/medium/content only where existing approved first-party tools support it. Avoid personal identifiers, persistent fingerprinting and raw IP/user-agent logs. Do not create a second tracker. Scope allowed: campaign_landing -> article_to_resource_click -> independently confirmed signup through existing provider -> affiliate_outbound_click (post-approval) -> external merchant-confirmed paid conversion -> refunds/fees -> realized net revenue.
`affiliate_outbound_click != sale`; `checkout_start != sale`; `confirmed_signup != paid_customer`. Unknown merchant-to-source joins must be marked unattributed. Do not assign fictional sessions to a source. External merchant totals without session join are reported separately.

## Calculations for 7- and 30-day cohorts
If independently verified qualified-human session count Q > 0 and settled realized net revenue R exists with fees, refunds and attribution scope documented, report `1000*R/Q`. Else report **NOT COMPUTABLE**. Paid conversion rate = distinct verified paid orders / qualified sessions with scope and attribution caveat. Lead-to-customer = confirmed attributable paid customers / confirmed leads where join possible. Never substitute traffic views as Q. Annotate tiny samples; report periods and censoring due to delayed settlements.

## A/B protocol (hypothesis, not measured lift)
- Eligible audience: human, high-intent readers entering one product-comparison landing page with verified attribution and consent.
- A = no video; B = same substantive information plus original optional 42s captioned/poster film. Film is **not encoded or hosted** in this PR, so an actual A/B cannot begin.
- Primary outcome = verified net revenue per 1,000 qualified human sessions after merchant/paid-order reconciliation, not click-through. Secondary = completed verified paid orders; confirmed leads; relevant CTA interest; load and accessibility cost.
- Equal first-party allocation if experimentation authorized; reject traffic-source imbalance, copy differences, forced video, missing captions, screen-reader inconsistency, significant mobile degradation. No sequential significance claims on tiny samples. **Stop experiment if** no verified affiliate authorization or inability to distinguish refunds, direct returns and commissions.
- QA widths 360/390/768/1440/1920; contrast, keyboard focus, reduced motion, native disabled state, no-JS, no double form; genuine video only with captions, transcript and user controls when produced.
