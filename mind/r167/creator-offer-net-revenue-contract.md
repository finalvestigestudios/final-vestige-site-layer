## Privacy-safe attribution contract

Grok controls each actual asset_id. Claude/site QA own event implementation—no duplicate scripts, cookies, fingerprints, pixels, or new SaaS. Standard UTMs where allowed: `utm_source=tiktok|youtube|instagram`, `utm_medium=organic_social`, `utm_campaign=mind_attn_pilot_2026_11`, `utm_content=<GROK_VERIFIED_ASSET_ID>`. Reject unknown IDs rather than guessing. Retain allowed, bounded UTM values as campaign aggregates only; exclude user emails, names, raw IP addresses and sensitive query strings. Use existing first-party measurement if permissible; user consent and privacy policy must govern.

Event specification (implementation pending): `campaign_landing` with valid asset_id, landing route and consent context; `article_to_resource_click` for internal free CTA; `focus_confirmed_signup` only if Jetpack authoritative confirmation is observable; `offer_view` for eligible independent guide exposure; `affiliate_click` only if link becomes authorized, distinct from `merchant_confirmed_paid_order`; `affiliate_commission_paid` only from authorized merchant report; `refund`, `fees` from settlement. Do not infer a merchant checkout start from a link click. Define qualified-human sessions with documented bot exclusion, not total pageviews.

7- and 30-day cohorts by verified published asset: qualified sessions `Q`, confirmed paid orders `P`, gross `G`, refunded `R`, platform/processor/affiliate fees `F`, other directly attributable transaction costs `C`; realized net `N=G-R-F-C` using actual reconciled settlement data. **Primary KPI: `1000*N/Q` when and only when Q>0 and all material components verified; else NOT COMPUTABLE.** Paid conversion rate `P/Q`, and lead-to-customer `P_from_confirmed_leads/confirmed_leads` only if lawful, reliable cohort-level linkage exists. `affiliate_click` is a diagnostic, not a paid sale. Show tiny sample warning until at least 100 qualified sessions per variant and 20 total verified purchases across variants; even then do not claim significance without suitable statistical methodology. These thresholds are review conventions, not guarantees.

## Controlled A/B hypothesis and implementation boundary

**A:** Complete original source-based text-only Zen12 guide. **B:** The same text + one user-initiated, 42-second original video with genuine captions, transcript and optimized poster. Preserve identical CTA copy, placement, price statement, disclosure, entry audience and referral parameter conventions; do not hide free alternatives in either arm. Require actual accessible video before activating B. Favor server-side deterministic per anonymous visit if existing infrastructure and consent allow, with no persistent user ID; avoid client-side split scripts or fingerprinting. Keep no-JS variant fully navigable.

Primary endpoint = merchant-verified net revenue per 1,000 qualified human sessions, not CTR or time on page. Secondary = confirmed paid orders and confirmable leads; diagnostic = resource or affiliate CTA clicks. No launch while purchase link or sale reporting is absent. Guardrail video cost: self-hosted short compressed MP4/WebM, poster, `preload="none"`, no autoplay, no third-party JS, run mobile LCP/CLS before release. Native media controls, text transcript, accurate WebVTT caption file, keyboard/screen reader and reduced-motion checks required.

Decision rule: no winner from small samples, uncertain attribution or non-significant differences. Stop if disclosure becomes less conspicuous, mobile performance falls materially, consent or accessibility fails, or the post-to-landing promise is inaccurate. If neither sale path can be authenticated, stop commercial experiment and continue only free research.
