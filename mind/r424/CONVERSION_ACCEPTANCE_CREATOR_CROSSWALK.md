## 3. Controlled A/B hypothesis — a design, not an outcome

**Variant A:** ZEN12_A_TEXT_GUIDE.html is an accessible full text-only source guide. **Variant B:** ZEN12_B_OPTIONAL_FILM.html contains the SAME primary guide copy and an original 42-second poster, storyboard, transcript and caption concept in ZEN12_OPTIONAL_42S.vtt. **B has no playable video file**. No autoplay, third-party player, consent-free download, hidden copy or fake play button.

**Hypothesis:** Optional video might improve buyer understanding and purchase intent relative to text alone; it might also slow mobile reading or distract. It is NOT guaranteed to convert. Do not run a claimed A/B trial until both pages have the same actual approved price, CTA, placement/disclosure, offer and independent on-device QA. A real encoded original video must be keyboard accessible, no autoplay, captions reviewed in context, transcript accessible, media downloaded only on interaction, low-byte poster, reduced-motion support and privacy review.

**Assignment:** Use random variant assignment only if existing Claude first-party infrastructure already supports privacy-safe server allocation without additional cookies, fingerprints, PII or tracking vendors. If comparable assignment and verified merchant-paid transaction matching cannot be lawfully established, document the result as qualitative editorial usability, NOT a statistically identified paid-conversion effect. Monitor 360/390/768/1440/1920 widths, no JS, WCAG 2.2 AA, CWV. Freeze 7- and 30-day cohort reporting, deduplicate verified provider transactions, show N and intervals, avoid tiny-sample verdicts.
