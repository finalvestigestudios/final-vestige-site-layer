## Event contract (design only; no script deployed)

`qualified_landing_session`: coarse privacy-safe session count, first-party, with **verified** incoming Grok `asset_id` and `utm_campaign`; no email, IP or raw IDs exported to page markup.

`focus_click`: click into existing `/focus/`. Not a lead.

`focus_lead_confirmed`: only after Jetpack independently confirms subscription/permission; attributed only if lawful and supported. Existing welcome remains unchanged.

`affiliate_click`: user-initiated outbound earning link click only **after authorization**, with adjacent FTC disclosure. Never sale.

`paid_order_confirmed`: actual paid merchant order with accepted reporting and deduplication; no invented order IDs.

`affiliate_commission_settled`: independent merchant report with payable commission and refund/fee adjustments. No inferred value from link click.

`net_revenue`: actual collected FV product revenue plus settled eligible affiliate commissions, minus refunds, processing costs and applicable fees, with a documented period. Formula: `1000 × net_realized_revenue / verified_qualified_human_sessions`; report **NOT COMPUTABLE** if missing either verified numerator or denominator. Track 7- and 30-day cohorts, avoid small-N false precision.
