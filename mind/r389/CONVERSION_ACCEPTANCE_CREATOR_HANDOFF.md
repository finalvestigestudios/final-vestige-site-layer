## Controlled A/B buyer hypothesis

**A:** Original static evidence-first buyer guide. **B:** Precisely the same substantial guide plus an optional 42-second original captioned video, no autoplay or external iframe. Currently B supplies the storyboard, poster, VTT and transcript only. Neither version is a functioning sale.

**Question:** Does adding a short optional source-grounded explanation improve independently confirmed, net paid conversion per qualified human session without worsening mobile usability or comprehension? B might perform worse: this is a falsifiable hypothesis, not an expectation.

Before launch, encode original rights-cleared video, verify transcript/caption synchronization, real 360/390/768/1440/1920 browser WCAG 2.2 AA, no-JS content, keyboard, touch, reduced-motion, WordPress sanitizer, site Core Web Vitals and mobile payload. Confirm exact partner-approved domain/link/checkout/disclosure first. Randomization and instrumentation belong to Claude; no duplicate scripts, nonconsensual identifiers or paid software. No result should be called statistically meaningful on a tiny audience.

**Primary metric:** realized net revenue per 1,000 qualified-human sessions, using mature 7/30-day cohorts. Include independently confirmed paid orders, eligible affiliate commissions or paid FV receipts, refunds, chargebacks and attributable transaction fees; report missing attribution explicitly. Do not call purchase-intent clicks or provider-unconfirmed leads paid orders. Only claim a paid sale when the independently reported merchant order/settlement can be reconciled.
