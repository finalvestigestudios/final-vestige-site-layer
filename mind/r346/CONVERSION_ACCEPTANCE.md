Use **only** Claude's approved existing first-party analytics and consent stack. No additional scripts, pixels, third-party SaaS, fingerprinting, visitor email capture, full IP logging or identity-in-URL. Track separate semantic events:
- **qualified_human_session:** session after documented bot/internal-traffic filtering, with privacy/consent criteria, not merely a pageview.
- **campaign_landing:** eligible session actually arriving at named existing live article.
- **article_to_fieldbook_click:** first-party navigation to existing Focus route, not a confirmed signup.
- **confirmed_signup:** only server/provider-confirmed consent, not a CTA click, and only if attributable without disclosing email.

## Test hypothesis, not a conversion guarantee

Variant A: polished source-based text-only Zen12 buyer guide. Variant B: same complete text with original optional 42-second poster/film and human-readable six-scene transcript. Both share exact offer, near-CTA affiliate disclosure, content, navigation, disabled CTA and one existing Focus path. Hypothesis: film may help comprehension and trust for some social arrivals; null hypothesis no improvement. Primary readout is verified paid order/net revenue per 1000 humans, once an authorized merchant route exists. Secondary: confirmed leads and source engagement; monitor mobile CWV, disclosure comprehension, trust and accessibility. At tiny samples show intervals and avoid definitive lift.

**Media note:** R346 B file has a static original SVG poster, transcript and caption VTT only; no encoded film is embedded or hosted. Earlier separate original video proofs do not convert this page into a completed media test. When staged, require paused by default, user-initiated play, captions synced to the encoded file, keyboard controls, reduced-motion/no-JS operation and optimized media costs.
