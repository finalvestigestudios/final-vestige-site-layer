## Synthetic-only privacy model
The `attribution-privacy.mjs` module is **hard off** and has no network or storage. It only accepts five coarse enumerated string fields—source bucket, topical bucket, candidate variant, event bucket and destination bucket—**if activated by future separate code after authorization**. It rejects arbitrary URL/referrer/UTM, email, phone, IP, cookie, user ID, session, UA, timestamps, click IDs, and arbitrary source strings. It suppresses synthetic groups smaller than ten; that alone is not sufficient privacy protection against differencing or repeated queries. Do not reuse this as turnkey production tracking. Any actual deployment requires a privacy impact assessment, consent/legal review, minimum cohort and aggregation policy, retention/notice plan and partner terms.
