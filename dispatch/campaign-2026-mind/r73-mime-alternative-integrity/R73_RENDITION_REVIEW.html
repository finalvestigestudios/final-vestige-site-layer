What the other email actually says.

A plaintext body can carry a disclosure, a mailing address, and an unsubscribe link while the HTML rendition silently omits them. The earlier inspector could report a reassuring result anyway. R73 fixes that blind spot.

SYNTHETIC REVIEW · HOLD_UNSENT · NO EMAIL SENT

01 / An unrelated link is not an unsubscribe.

False positive in older inspector

Unsubscribe anytime. Read the full investigation: https://finalvestige.com/focus/

The word “unsubscribe” and a separate HTTPS link were previously sufficient to claim a possible plaintext opt-out.

R73 corrected interpretation

No labeled plaintext opt-out destination detected.

Unsubscribe: https://unsubscribe.example.invalid/u/SYNTHETIC_ONLY

The second block only illustrates linked syntax. It is not a real unsubscribe endpoint or proof the mechanism functions.

02 / Two renditions, one missing address.

Plaintext MIME alternative

Research first. P.O. Box 123, Example City, CA 90000 Unsubscribe: https://unsubscribe.example.invalid/u/SYNTHETIC_ONLY

The illustrative postal address is fictional. It is NOT Final Vestige's verified mailing address.

HTML MIME alternative

<main> <p>Research first.</p> <a>Unsubscribe</a> </main>

HOLD: Publisher address missing in HTML rendition.

The parser must not combine fragments of two different alternatives to construct imaginary compliance.

03 / A commercial disclosure must survive the format switch.

Plaintext candidate

Potential recommendation: Zen12. Final Vestige may receive a commission from an optional qualifying purchase. No active earning link.

This illustrative text is not approved merchant promotional material.

HTML candidate — missing key sentence

<p>Zen12 is a twelve-minute audio product.</p> <p>Continue to the review.</p>

HOLD: Commission disclosure missing early in HTML.

Even if the plaintext alternative passes, HTML-first recipients might never see a disclosure. Both versions require editorial review.

04 / A one-click header is not a functioning one-click unsubscribe.

Unsupported claim

List-Unsubscribe-Post: List-Unsubscribe=One-Click List-Unsubscribe: <mailto:remove@example.invalid>

No HTTPS one-click destination accompanies this declaration.

Better syntax, still not verified

List-Unsubscribe: <https://unsubscribe.example.invalid/u/SYNTHETIC_ONLY> List-Unsubscribe-Post: List-Unsubscribe=One-Click

Even this syntactic candidate requires separate authorized functional verification. A static reviewer cannot make that assertion.

Production gates do not move.
