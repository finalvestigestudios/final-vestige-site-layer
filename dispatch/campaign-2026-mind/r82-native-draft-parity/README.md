## Problem this resolves

Excellent source-controlled manuscripts and simulated HTML newsletters **do not establish** what is in the native post editor. Jetpack is configured for excerpt mode; **post title** sets the email subject and **custom post excerpt** can drive the received introduction. A wrong title, absent custom excerpt, selected send toggle, or scheduled draft can undermine offline copy QA. This comparator checks those specific fields against the six *optional* R81 proposals. It **cannot send**, approve or certify a message.

**This is not an actual Jetpack-delivered email.** A native Preview email has not been observed, and a delivered MIME sample does not exist.\n\n**Never mistake a green structural comparison for send authorization.** Post-level "Send this post to subscribers" can be turned on even when site-wide new-post automatic sending is OFF. A post-level flag may need to be enabled to preview the native email, so opening even that native preview requires a separate founder permission and operational guard against publication.

`EXPECTED.json`: exact six R81 subjects, excerpt texts, research sources and editorial URLs pinned to their source SHA, with only Issues 03 and 05 reserved for commerce. They are **not** approved substitutes for the original #175. `OBSERVATIONS.json`: genuinely **empty** because no native posts were created/inspected and no emails were authorized. It is not fake test data. `compare_draft.py`: read-only local comparator; rejects any input fields not explicitly permitted and never echoes raw user inputs. `RELEASE-DECISION.md`: evidence and owner-ready next steps.
