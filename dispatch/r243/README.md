## Fresh operational finding that matters before preview

[Official WordPress preview instructions](https://wordpress.com/support/newsletter/email-appearance/) explicitly say the per-post **“Send this post to subscribers”** toggle must be **ON** for the native **Preview email** option to appear. That is a **draft-only hazardous editor state**, not consent to send. Global automatic-send remains OFF. Without specific approval to create a throwaway *unpublished* post and enter the email-enabled draft state in a controlled session, the real native preview cannot be marked verified; **never click Publish or Send test email**. Other native controls may differ by plan/site; reverify in the actual editor rather than assume. [WordPress send flow](https://wordpress.com/support/newsletter/send-newsletter-emails/). This resolves the misleading shorthand “preview with email disabled”: global default-off is different from the per-post editor toggle.
