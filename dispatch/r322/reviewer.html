One site subscription, two pathways

01 / New email subscriber

  1. Visitor chooses the site's existing subscribe form.
  2. Jetpack sends a verification email.
  3. Visitor confirms through the actual email link.
  4. Provider records new site subscription, consent and email eligibility.
  5. Welcome message is configured; receipt must still be witnessed.

Count only a genuinely authenticated, unique confirmation event — never the form submission.

02 / Existing WordPress account

  1. A signed-in WordPress.com user chooses to follow the site.
  2. WordPress may skip a separate confirmation email.
  3. Provider records a genuinely new site-subscription activation.
  4. Confirm explicit Dispatch permission and actual email delivery preference, not Reader-only status.
  5. Welcome may arrive without a confirmation email; verify independently.

Count only a new provider-confirmed enrollment event — never just seeing an old active subscriber.

Official source: WordPress Newsletter Settings, reviewed October 26, 2026. Routes modeled here are not proof that provider event-level data is available in the connected API.
