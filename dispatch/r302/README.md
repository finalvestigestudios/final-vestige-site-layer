## Material finding (2026-11-12)

Original Issue 04 subject **“Fourteen seconds. A much longer explanation.”** contains an unexplained number. NASA's public history instead says **17 seconds** between the first reported fire indication and the last crew communication. A 1967 Board chronology gives timestamps, while the detailed investigation describes ambiguity in interpreting some voice recordings. A time interval without an explicit start and end is not source-safe. The replacement deliberately avoids a numeric headline and distinguishes approximate **17-second communications** from a **90-second ideal opening time** and approximately **five-minute rescue hatch access**. Neither is the full fire duration. Avoid calling any number the exact time to death.
