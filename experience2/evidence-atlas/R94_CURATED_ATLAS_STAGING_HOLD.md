# Apollo R94 · Curated Atlas — STAGING HOLD

This branch introduces an actual text-first, six-record Apollo source Atlas rather than speculative historical map pins. The builder takes real R93 source-passport output, itself sourced from the validated R92/R91/R90/R86 Research Desk and Evidence Atlas. Each entry includes a NASA link, catalog claim, photograph date and certainty, what the source can and cannot establish, pending photo-specific image rights, and native same-record SourceDrawer links to passports, EvidencePlates, ChronologyRail and NASA source rights board.

The six records are displayed in register order, NOT accident chronology. Five have specific-day photography metadata; the crew portrait has only January 1967 and its proposed S67-19766 identity remains provisional. Two 2017 tributes share January 24 without a claimed order. No external media, map pins, inferred event connections, external scripts or paid services. Native HTML contains every record even without JavaScript. Optional JavaScript only adds filter/search, accessible pressed state, announced counts and a recoverable empty state; print displays all six NASA links and image reuse disclosures.

Run unittest with -p test_curated_atlas_r94.py.
