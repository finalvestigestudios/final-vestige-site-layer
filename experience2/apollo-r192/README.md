# Apollo R192 — printed-PDF source custody acceptance (DRAFT / STAGING HOLD)

Part of Experience 2.0 Issue #150 and conversion-governance Issue #820 / charter #818. This PR is **stacked on R191 / PR #1419** at `8df9540874607e49ac71e63dcf423ff365cb7e16`. It is deliberately isolated from homepage PR #49, Research Desk PR #158, and all live WordPress, commerce, email and social surfaces. No deployment is authorized.

## Why

R191 proved that a print-only NASA source index appeared in Chromium **print-media mode**, but it did not yet export a PDF and examine whether the resulting file retained text, visible full URLs, clickable official source annotations or the one original investigation CTA. R192 supplies that missing physical-output gate. This is a QA implementation and creates no new historical narrative or commercial placement.

## Run

From a clean checkout of this draft PR's head, build the parent R191 source using its existing pinned generator and source inputs (`python experience2/apollo-r191/build_r191.py`). Then execute:

```sh
python experience2/apollo-r191/qa/test_r191.py
python experience2/apollo-r191/qa/pdf_custody_gate_r192.py /tmp/apollo-r192-proof
```

Requires `php`, Python Playwright, Chromium at `/usr/bin/chromium`, and PyMuPDF (`fitz`) on an **isolated** QA machine. No outbound network, paid service or plugin activation is required. The HTML is generated by the existing PHP shortcode under a WordPress-function shim; the Chromium session uses `page.set_content`, not a real WordPress installation or HTTP navigation. External NASA destinations are checked against the approved source ledger, not fetched by the PDF script.

## Scope and acceptance

The gate uses **real Chromium `page.pdf()`** at 390px and 1440px with JavaScript disabled, producing A4, 5-page searchable documents in the tested fixture. Using PyMuPDF, it verifies that all eight approved NASA technical/photo/rights URLs appear as printable literal text *and* actual clickable PDF hyperlink targets, the free original-investigation CTA remains clickable, the ignition uncertainty and NASA non-endorsement cautions are present, the source appendix appears once, pages are nonempty, and no text span is outside page bounds. It renders selected pages back to PNG and records SHA-256 digests for repeatable visual evidence. A deliberate wrong source link is rejected by the validator.

## Local results — 2026-11-07

- Source ancestry: four executable R191 files independently checked against their actual GitHub blob SHAs.
- Parent R191 Python/PHP regression: **10/10 PASS**.
- R192: two independent complete runs, two PDF contexts per run (390/1440), **8/8 clickable and visibly printed official URLs per context**, one active investigation link, five readable pages per output, zero off-page text spans. Negative-control altered NASA anchor **correctly rejected**.
- PNG pixel output SHA-256 matches across both runs for all 6 selected page snapshots (3 pages × 2 contexts). Raw PDF files are **not byte-stable** due to Chromium metadata; their raw SHA values differ. This does not imply visual differences. Repeatable PNG hashes and structured reports are the deterministic acceptance evidence.
- **NOT RUN:** genuine axe-core, native assistive-technology testing, installed WordPress/Gutenberg/Assembler acceptance, actual browser HTTP navigation, CDN/CSP, CI at exact GitHub head, real-user LCP/CLS/INP, or paid-order attribution. The environment blocks Chromium file/localhost URL navigation. A PDF alone cannot establish accessible screen-reader navigation or real Core Web Vitals.
