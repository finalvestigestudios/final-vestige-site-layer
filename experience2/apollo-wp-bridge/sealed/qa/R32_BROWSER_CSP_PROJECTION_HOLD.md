# Apollo R32 — real Chromium enforcement of a projected CSP (DRAFT / HOLD)

This is an isolated security and accessibility QA enhancement stacked on Apollo PR #378. Homepage PR #49, Research Desk PR #158, live WordPress and its settings are not modified. Do not install or merge without independent review.

## Purpose and exact boundary

R31 verified the actual PHP-generated HTTP response, its rotating CSP nonces, six NASA records, six media-rights holds, one unresolved photograph catalog identity and zero invented Atlas coordinates. Direct Chromium navigation to localhost and to intercepted HTTPS test names is blocked by this execution environment with ERR_BLOCKED_BY_ADMINISTRATOR.

R32 exercises a narrower but genuine browser behavior: capture the unchanged R29 SHA-pinned private PHP staging response over local HTTP (mock WordPress auth), validate it with R31, then project its exact CSP into a meta Content-Security-Policy tag before the original HTML/CSS/JS using Playwright page.set_content. The HTTP-only frame-ancestors directive is validated statically and omitted from the meta projection. All other directives must match the strict pinned policy exactly; missing, duplicated, unknown or weakened permissions are rejected.

Seven real Chromium viewport runs (320, 360, 390, 768, 1024, 1440, 1920) require the legitimate nonce-authorized JavaScript and stylesheet to function while injected untrusted inline scripts/styles fail under browser CSP. An off-domain script attempt must fail with the browser's CSP requestfailed reason; no route/network fetch can occur. The same original evidence and source-hold constraints must survive. Keyboard and touch disclosures, no-JS access and reduced-motion emulation are exercised. Chromium PerformanceObserver provides explicitly SYNTHETIC about:blank document LCP/CLS, NOT website field metrics.

## Reproduce

Prerequisites: exact checkout of this draft branch with sibling R31 http_response_gate_r31.py, Python 3 with Playwright, Chromium and PHP. Obtain the R29 sealed staging ZIP matching SHA-256 d29ee02d629ae50716058b8ffa6cb3d9bac76a9cd72d9e3387504e2d22dab14f.

Run Python unittest discovery on experience2/apollo-wp-bridge/sealed/qa using pattern test_browser_csp_projection_r32.py, then execute browser_csp_projection_r32.py with three arguments: --r29-zip pointing at the pinned ZIP, --shots pointing at a writable QA screenshot directory, and --report pointing at the requested JSON receipt. The gate rejects a mismatched ZIP or embedded PHP before launching the browser.

## Non-waivable release limitations

It does NOT prove browser enforcement of HTTP headers, HTTP-only frame-ancestors, real WordPress cookies/nonce/session checks, private WordPress staging integration, axe-core accessibility, mobile Safari/VoiceOver, media reuse rights, hosted LCP/CLS/p75 CWV or a passing GitHub Actions job. Six images remain links only; S67-19766 remains unresolved and no Atlas coordinates or edges are admitted. Independent QA and founder approval are mandatory before any site changes, installation, merge or deployment.
