# Apollo R426 · Six-source Atlas Comparison (STAGING ONLY)

An isolated, opt-in PHP shortcode and scoped stylesheet for a chronological Apollo 1 evidence experience. Built to prevent the known failure where an authentic NASA photo is positioned as proof of an unrelated fact. Six direct NASA catalogue links, dated metadata and individual limitations remain available without JavaScript. Three source-grounded historical stages deliberately do not imply a map or invented connection. CTA goes **only** to the already-published free Apollo investigation. No Payhip SKU is asserted.

**Invocation:** do not install automatically. Authorized reviewer must set `FV_R426_ENABLED=true` and `FV_R426_STAGING_PAGE_ID=<approved staging page ID>` after staging review. `[fv_apollo_source_comparison_r426]` renders only on that staging page, otherwise an ordinary free-investigation fallback. No customer data, tracking, WordPress content writes, NASA image downloads, media uploads, checkout actions, emails, or paid services.
