## Why this gate
Earlier tests validated source identity, link names, sizes and layout, but **did not systematically check computed text contrast across the open SourceDrawer and all native source disclosures**, or verify that the print-only full-URL bibliography is actually visible in print media across responsive widths.

Run the committed `qa/r242_compact.py` against the SHA-pinned **R238 generated Atlas**, which is generated by the actual PHP adapter and verified before execution. The historical fragment remains unchanged. Open all disclosures, inspect visible text nodes' computed color/background composition and minimum WCAG 2.x authored-color contrast ratios (4.5:1 normal; 3:1 large), check the real Chromium accessibility-tree source link names, check a print-only source appendix with explicit NASA URLs, and retain the one free investigation CTA. Test JS on/off, responsive 320/390/768/1440/1920, reduced motion and a forced-colors fixture at 768.

This is a **focused automated contrast gate, not a WCAG certification**: it does not model images/gradients, screenshot-antialiasing or screen-reader user experience. Forced-colors mode is inspected for source accessibility but excluded from authored-color contrast calculations. DOM print-media visibility is tested, **not** a physical printer or PDF rendering.
