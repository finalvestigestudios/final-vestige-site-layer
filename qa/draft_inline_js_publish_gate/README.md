# Final Vestige draft inline-script publication preflight (HOLD-only)

Offline read-only QA for **unpublished** WordPress draft/pending/future/private pages. This complements (rather than repeats) the existing published-page rendered JS census and actual-host Focus A/B. Before Claude or QD approves publication, compare the exact latest Gutenberg **saved** HTML with WordPress's **rendered** HTML from the same page revision. No WordPress writes or subscriptions are performed.

Use `node --test gate.test.cjs`; use `node gate.cjs /path/to/local-private-snapshot.json`. Input file (never commit it) contains `{ "pages": [{ "id": 2017, "status": "draft", "saved_html": "...", "rendered_html": "..." }] }`. Both content strings come from authenticated **read-only** WordPress `pages.get` with `context=edit` and `context=view` respectively, captured back-to-back. Store them outside Git; do not include subscriber data, credentials or private Apollo text in commits or CI artifacts. The tool never logs content, script strings or source excerpts; only page IDs and failure kinds.

A `HOLD` finding is a **source-level publication risk**, never proof of a public browser defect. `PASS` does **not** establish browser execution, CSP allowance, keyboard accessibility, media decode, actual email receipt, PDF integrity, rights clearance or release permission. Failures with `script_count_changed` may be caused by intentional WordPress transformations and demand human review. Module script is an explicit unverified HOLD. After approved edits, rerun the saved/rendered test and a real browser/console test. No change to finalvestige.com, draft Apollo page 2017, retired draft water pages 29/85, or frozen homepage PR #49 is authorized here.
